# 需求与验收

状态更新2026-10-27，v2：首版已有运行记录，本轮15项反馈对应的源码和隔离验证已完成；运行版切换与重启后真实服务验收仍待主任务完成。以下保留长期目标契约，当前结果与边界见README、07-handoff和v2计划；复杂反复、结构对齐、自动备份和跨平台尚未完整实现。点击练习语义以本轮R08为准。

## 范围

第一版以单用户、单声部主旋律、中文歌词、简谱图片为主；保留多声部和多段歌词的数据能力。复杂钢琴谱、手写谱、多声部自动分离和完整伴奏生成不作为首版承诺。五线谱首先是同一主旋律的另一种显示方式。

用户已明确：原音频独立变速与移调暂不考虑；本期原音频保持原速、原调。钢琴播放及参考线仍支持移调、八度与倍速。跨平台仅关注语言选择、模块边界和可迁移性，具体迁移、打包、手机离线与同步暂不考虑。以上限制不取消原音频 offset、分段对齐、选句和循环。

| 编号 | 功能 | 可观察的验收结果 |
|---|---|---|
| R01 | 一张或多张谱图与对应音频导入 | 保留原件、导入顺序、哈希和元数据；支持排序、旋转、局部裁剪，失败可重试 |
| R02 | 本地 VLM 读谱 | 服务端通过配置连接 远程 GPU 服务器 现有模型；输出结构化音符、节奏、歌词、原图位置与不确定项 |
| R03 | 跨图重叠处理 | 展示候选重叠与合并范围；可接受、撤销、手动分割；不误删真实重复乐句 |
| R04 | 人工纠错 | 改音高、八度、时值、休止、歌词、连音、分句和重复结构；可撤销与恢复版本 |
| R05 | 简谱、五线谱、歌词、MIDI、钢琴声 | 同一版本派生，各视图定位同一音符；只凭谱面即可生成 MIDI，经钢琴音源播放或导出 WAV；可导出 MIDI、MusicXML、歌词文本与完整工程 |
| R06 | 原音频与钢琴切换 | 在当前音乐位置切换；不会突然回到开头或同时产生两路非预期播放 |
| R07 | 钢琴转调、八度和速度 | 明确区分调性、半音移调、八度、音名显示；钢琴速度独立于音高；原音频固定原速原调，两种模式的参数和切换行为清楚可见 |
| R08 | 点击练习 | 点击音符或字，从该音前可调预备拍开始继续播放，默认1拍；整句播放为明确独立操作；对齐页点音只选择，不打断原音频时钟 |
| R09 | A/B 循环与间隔 | 谱面先点A再点B，含B音完整时值，选择不自动播放；支持清除、无限或指定次数，间隔为真实秒数，变速不改变间隔 |
| R10 | 原音频校准 | 整体正负 offset、拖动锚点、分段对齐；可表示前奏、间奏、漏唱、重复次数差异 |
| R11 | 实时音高 | 时间横轴、音高纵轴；显示实际曲线、当前频率/音名/音分；静音或不可靠段留空 |
| R12 | 灵敏度与降噪 | 独立控制噪声门限、音高可信度、平滑、频率范围、降噪预设；可校准环境底噪 |
| R13 | 参考线 | 可关闭或显示谱面阶梯线；钢琴/无伴奏练习跟随移调、速度和循环，原音频模式跟随已校准的原唱时间与音高；原唱实际曲线为可选扩展 |
| R14 | 录音和回放 | 记录人声与当时练习参数，回放时还原参考线和循环时间，支持多 take 管理与导出 |
| R15 | API 管理 | 多配置、模型名、地址、鉴权引用、图像限制、超时、重试、连通测试和默认选择 |
| R16 | 可迁移架构 | Windows 网页服务首站独立目录，不硬编码盘符；隔离平台能力以便后续 Ubuntu、桌面与手机复用，具体平台操作暂不纳入交付 |
| R17 | 数据保护 | 原件不覆盖；模型调用失败不破坏工程；备份可恢复；日志不含密钥 |

## 需要后续用实际素材确认的边界

- 远程 GPU 服务器 的现有模型、服务协议、端口、多图限制、结构化输出能力尚未知。
- 同一套歌谱可能与 MP3 存在结构差异；不能保证只靠 offset 就能对齐。
- 用户“do 是 C3 还是 C4”暂解释为实际演奏八度变化；保留单独的音名编号显示选项。采用中央 C=C4、MIDI 60 的内部约定。
- 无谱面速度时要求指定或估算速度并标记待确认；无歌词时可以手填，自动识别歌唱歌词为可选扩展，不伪称图片含有歌词。
- 默认本机个人使用；手机访问、离线能力与多用户共享目前不要求用户决定。
