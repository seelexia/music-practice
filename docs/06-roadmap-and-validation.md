# 交付路线与验证

以下阶段保留为历史路线与长期退出条件。首版主流程已有实现，v2 源码与隔离验证已完成，但本文记录时运行版切换和重启后真实服务验收仍待主任务完成。当前进度见文末与 [交接](07-handoff.md)；不承诺未经测量的准确率、延迟或开发工期。

## 阶段

| 阶段 | 交付物 | 退出条件 |
|---|---|---|
| P0 设计 | 本组文档、边界、关键未知项 | 用户对设计方向反馈；当前已形成草案 |
| P1 技术验证 | 小型谱面模型、谱面独立生成 MIDI/钢琴声、钢琴变速移调与实时音高；远程 GPU 服务器 现有 API 核查 | 用实际谱图验证可纠错结果；证明钢琴播放与本机音高检测可行；记录音源许可证 |
| P2 端到端主流程 | 图片/音频导入、VLM、纠错、简谱/五线谱/歌词/MIDI | 一首歌完成导入到人工校正、保存、重开、导出 |
| P3 练习与同步 | offset/锚点、点击分句、音源切换、钢琴移调变速、A/B 与间隔 | 有重复/前奏/错位的歌曲可手动对齐并循环；原音频固定原速原调，切换恢复各自预设 |

| P5 稳定与部署 | Windows 可运行包、备份恢复、资源限制与文档 | 在不修改其他服务条件下本机运行；恢复测试通过 |

阶段为风险递减顺序。用户已明确暂不考虑原音频移调与变速；跨平台具体操作不在本期。P1 聚焦谱面识别、谱面驱动的钢琴音源和麦克风基频检测。

## 固定样例集

- 两张重叠一行的简谱，同一音符具有两个来源区域。
- 同旋律真实重复副歌，不能被当成重叠删掉。
- 升降号、上下八度点、附点、三连音、休止、弱起、连音、换拍和转调。
- 一字多音、多段歌词、重复句，点击应定位正确 occurrence 与乐句。
- 前奏 +2 秒、负 offset、渐进速度漂移、加间奏、漏唱一段与重复次数差异。
- VLM 超时、缺字段、无效 JSON、重跑与人工编辑冲突。
- 合成正弦音、谐波丰富音、颤音、滑音、噪声、静音、气声、低音与高音，附人工标注歌唱片段。
- 录音途中变速、移调、跳转、循环、暂停及设备拔出；长录音和进程中断。

素材应使用用户授权或自制样例。不能把真实私人音频写入公开仓库。

## 验证指标

- 识谱分别统计音高、时值、歌词、结构、重叠合并准确率和人工纠正时间，不能只给单一总分。
- 合并必须能复原原始候选与来源；正式版本重新识别后人工修正不丢失。
- 钢琴参数测试用已知音符、频率和时长检查“速度不改调、移调不改时长”；原音频只验证原速原调播放、定位、对齐和循环。
- 理想合成音可先以稳定段音高误差中位数 ≤10 cents 为候选目标；真人、噪声与八度错误分开测，不据此宣称现实准确率。
- 实时显示端到端延迟先以桌面有线设备 P95 ≤150 ms 为候选工程目标；P1 后按实测修订，并记录采样率、窗口、机器、浏览器和设备。
- 同步与循环误差测 P50/P95、长时漂移、音源切换与边界残音；先建立基线再冻结门槛，不能用视觉看着同步代替测量。
- 当前测试目标 Windows 浏览器；跨平台测试矩阵留待迁移时制定。无权限、设备断开、音频上下文挂起、网络中断、磁盘满和格式不支持有明确反馈。
- 导出/再导入与备份/恢复检查音符、歌词、原件哈希与版本，不只检查文件存在。

## 2026-10-27 实施状态

已形成P1–P5所述主流程的可运行首版，实际实现不代表所有长期退出条件已完成。真实VLM和B站资料/封面已接通，发布版及13项浏览器流程验证通过；真人设备延迟、逐音符准确率、结构差异对齐与备份恢复等仍待验收，详见07-handoff。首轮 13 项浏览器结果为 v1 历史，不能代替 v2 验收。


## v2 进度与新增决定（2026-10-27）

本轮完成用户 15 项反馈对应的源码实现：独立原音对齐、权威手动歌词与不可变旋律任务、分开的工作视图、连续速度、分行/小节/符号校验、纸面简谱、准确音符预备播放、谱面 A/B、数字/唱名编辑、可调分屏、设备选择、独立测音、自由网格缩放、录音记录与文件删除、QQ/网易歌曲链接解析。逐项边界见 [07-handoff](07-handoff.md)。

固定测试与隔离检查已完成：Rust 56 项通过、1 项默认忽略，前端 58/58，TypeScript 通过；模拟设备/API 的音频浏览器报告 12 项无运行时错误，只读样例源码预览亦无运行时错误。发布构建、3210 运行副本切换、首轮浏览器脚本的 v2 更新及重启后真实服务回归仍待主任务完成。真人歌唱、现实噪声、设备延迟和完整谱面准确率不在这些结果中。

| ID | 本轮决定 | 原因与验证边界 |
|---|---|---|
| D11 | 保守分行、最多4倍裁片、保留小节和符号证据 | 全页识别漏读细小下划线；逐小节和独立符号计算能揭示矛盾，但模型仍可能误读，不自动缩放。上部疑似谱行不得静默丢弃。 |
| D12 | 手动原文 + 独立歌词校对任务 | 准确文字与断句应有权威输入；只允许改歌词/乐句，旋律和其他字段必须与原稿相同，应用仍受版本保护。 |
| D13 | 时间编辑保留空拍，并丢弃过期小节引用 | 防止将稀疏时间轴从0重新编号，或显示与新时值不一致的印刷边界；固定夹具覆盖持续音跨小节、弱起和不等长小节。 |
| D14 | 点准确音符前预备拍；显式整句播放 | 用户第7项替换首轮默认整句语义；A/B第二音包含完整时值，选区与播放动作分开。 |
| D15 | 明确确认后删除单条录音及文件，文件暂存配合事务恢复 | 用户明确要求删文件；检查所属/类型/UUID/版本/路径，普通数据库失败恢复文件。进程崩溃暂存文件不等于跨系统原子性。 |
| D16 | 原音频时钟独立于谱面选择 | 缺前奏、旧时值错误不能靠随谱跳转建立可靠对齐；允许负offset，双锚点只估算当次钢琴练习速度，不改原音频或印刷BPM。 |

样例现有谱面没有被诊断响应或模型新稿覆盖；后续应先人工对照，再审阅应用。


## v5 interaction decisions (2026-10-29)

| ID | Decision | Reason / evidence |
|---|---|---|
| D17 | Keep browser-internal page fullscreen only in practice/pitch | User wants browser settings for display fullscreen; avoids duplicate controls. |
| D18 | Canonical event bindings plus OSMD zoom; adapt legacy tempo direction only for display | Beat/font previously never reached Staff; real synthetic XML exposed silent first-measure rejection. Tied fragments, gaps, playback/seek and SVG scale verified. No sample-specific logic. |
| D19 | Chromatic guide toggle and span-preserving pan in shared chart | Preserve continuous sung/reference data; common controls in all4pitch contexts, including recordings. |
| D20 | One-viewport resizable defaults, flex remaining space in page fullscreen | Old viewport−470/510px and fixed mobile overrides made cards too short or too tall. Internal panes scroll. |
| D21 | Client batch actions over existing per-song revision APIs | No schema/API migration; explicit filtered selection, per-item conflict reporting, reversible trash confirmation and file/history retention. No global atomicity claim. |

| D29 | 实时最新时刻默认50%并可拖至10%–90% | 窗口随真实采集时间平移而非时间线右端追踪；允许起始负视窗但不伪造数据，歌曲跟随语义不变。 |
